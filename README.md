# Sunao

A voice-first AI companion that listens, remembers, and talks naturally in Hinglish.

## Vision

Sunao is designed to feel like a real conversation, not a chatbot.

The goal is to create a voice-first AI companion that:
- Listens without judgment
- Remembers important context
- Helps users think clearly
- Provides emotional support
- Assists with life decisions through thoughtful questions
- Communicates naturally in Hinglish

Sunao is not intended to replace real human relationships. Its purpose is to provide accessible support, clarity, and companionship whenever needed.
